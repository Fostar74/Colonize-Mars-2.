# Alien Campaign — Side Quests

These quests are tracked server-side per player. They are unlocked after defeating Alien Base levels 1, 5, 10, 15 and 20 for the first time.

| Milestone | Reward (stored in Inventory reserve) |
|---|---|
| Defeat level 1 | 1,000 each Gold / Iron / Water / Solar |
| Defeat level 5 | 5,000 each |
| Defeat level 10 | 10,000 each |
| Defeat level 15 | 15,000 each |
| Defeat level 20 | 20,000 each |

Each milestone can be claimed once per player. These are initial balancing values, subject to change.

Alien attacks: 20 per UTC day; travel time 60 seconds outbound; permanent alien garrisons reset instantly per mission. Knight experience: one level for every 20 victories. The combat engine currently uses provisional unit statistics. Cyber Knight equipment modifiers, talents, and more granular combat formations require their final stat definitions before activation.
